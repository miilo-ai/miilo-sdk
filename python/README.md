Pydantic provider contracts for the [Miilo SDK](https://github.com/miilo-ai/miilo-sdk).
The language-neutral JSON Schemas and conformance fixtures live in the repository's
`protocol` directory.

```bash
pip install miilo-adapter-sdk
```

Implement the adapter protocol to expose a provider without moving its credentials
or orchestration into Miilo.
